# ECONA — public documentation

[RU](README.ru.md) | [EN](README.md)

**Status:** concept / research.

Status as of 27 October 2026.

ECONA is an independent research and design project for an ocean-going kite–solar–electric catamaran. The concept is being developed through analysis of current trends and advances in technology.

## Summary

The software-based engineering test environment has been restored on Windows. Hydrostatic calculations have been cross-checked using an independent method; the results agree within numerical precision. This does not establish the vessel's fitness for service.

The final weight statement and centre of gravity have not been established, and overall structural strength has not been validated. Assessments of dynamic stability, resistance and vessel performance are incomplete. Sea trials and full-scale testing have not been confirmed.

Images, diagrams, specifications, calculation inputs and results have been restored. CAD models, secrets and operational data remain private. It is not a completed design for construction; operational readiness and certification are not claimed.
