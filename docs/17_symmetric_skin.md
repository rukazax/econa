# Симметричная обшивка обоих поплавков

**Исторический этап v2.** Текущий состав модели описан в [подгонке компоновки v3](18_fitted_assembly.md): после следующего задания исходные группы заменены подогнанными деталями и удалены из рабочего файла. Ниже зафиксировано состояние до этой замены.

**10 октября 2026.** В единственный рабочий файл `models/ECONA/ECONA_ECONA.FCStd` добавлена группа **06 Симметричная наружная обшивка — оба поплавка**, с двумя отдельными CAD-оболочками: `PortSkin` и `StarboardSkin`.

![Симметричная обшивка в FreeCAD](../assets/geometry/symmetric-skin.png)

## Что изменено

Построена общая форма по наружным сечениям обоих исходных поплавков. Правый поплавок при сравнении отражён относительно Y=0; соответствующие точки контуров обоих бортов усреднены. Из общей формы получены две точно зеркальные поверхности. Симметрия относится к паре поплавков относительно диаметральной плоскости катамарана; внутренняя и наружная стороны отдельного поплавка не принудительно одинаковы.

Обшивка охватывает днище и борта, включая возврат внутреннего борта у узкого носа. Мост, надстройка, рули/шверты, внутреннее наполнение и переборки не перестраивались. Все 96 исходных объектов, их положения и геометрия сохранены. Исходная группа **01 Основная геометрия** скрыта только для просмотра новой обшивки; её можно показать клавишей пробел.

Толщина, материал, слои ламината и припуски не назначены. Это наружные поверхности, а не объём материала обшивки. Границы у палубы/стыка с мостом и кормового среза остаются открытыми; эти оболочки пока не дают корректного замкнутого объёма для расчёта водоизмещения.

## Способ восстановления

Использована исходная геометрия Mesh01. Наполнение не удалялось и не перемещалось: его поверхности учитывались только при анализе исходного набора. Сечения сняты в 139 продольных позициях, с основным шагом 100 мм и дополнительными позициями у переходов. Нижний контур определяется нижней огибающей, наружный борт — наружной огибающей. Для нижнего контура исключены исходные грани, пересекающие диаметральную плоскость, чтобы мост не стал частью поплавка. Погружённые навесные элементы отделены от обводов; в узком носу восстановлен возврат внутреннего борта.

В каждом сечении отдельно сопоставлены внутренний склон днища, плоский участок днища и наружный борт. Усреднение выполнено по относительной длине соответствующих участков. Узловые точки обоих исходных контуров сохранены в построении; между сечениями образована непрерывная поверхность из плоских граней. Исходные фасетки заменены новой реконструкцией только в добавленных объектах, а не в исходной компоновке.

Для отделения поплавков от надстройки использован верхний предел сечения Z=1950,2 мм и граница области у соединения с мостом |Y|=1808,590 мм. Это явные геометрические правила текущей реконструкции, не утверждённые строительные границы. Внутренний борт у носа восстанавливался отдельно по его огибающей.

Расхождения соответствующих точек исходных наружных контуров: 95-й процентиль **9,19 мм**, максимум **136,89 мм**. Это разница источников до усреднения, а не погрешность симметрии. Неоднозначные переходы исходной сетки, особенно соединение с мостом, требуют конструктивной проверки при дальнейшем проектировании. Готовые исходные параметрические обводы из экспортов не получены.

## Результат и проверка

| Параметр | Результат |
|---|---:|
| Число новых CAD-оболочек | 2 |
| Плоских граней на один поплавок | 19 447 |
| Площадь созданной открытой поверхности одного поплавка | 58,0066 м² |
| Исходных объектов сохранено | 96 |
| Исходных сеток проверено без изменения вершин и топологии | 42 |
| Симметрия CAD-вершин | Совпадение после отражения Y при округлении до 0,000001 мм |
| Проверка CAD | Обе оболочки корректны, по одной связной Shell на поплавок |

Площадь относится именно к созданной открытой поверхности; она не включает припуски и не заменяет ведомость раскроя. Положения исходных объектов и исходные сетки проверены точно. Сравнение численных характеристик исходных CAD-линий/граней выполнялось с допуском 10⁻⁷ мм для учёта округления вычисляемых величин при повторной записи; геометрия не редактировалась.

Сохранённый документ проверен отдельным процессом FreeCADCmd против снимка до добавления обшивки. Реестры: `research/geometry/symmetric_skin.json`, `symmetric_skin_validation.json`, `symmetric_skin_cleanup.json`. Это обновление рабочего файла; прежний аудит `ECONA_validation.json` относится к исходной версии до добавления обшивки.

Для просмотра раскрыть группу **06**, выбрать оболочку и нажать **пробел** для переключения видимости. Чтобы посмотреть исходное наполнение, показать группу **01**; её исходная обшивка тоже станет видна, поскольку прежние поверхности сохраняют первоначальную группировку.
