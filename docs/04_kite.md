# Кайт: тяга, запуск, возврат, автоматизация

Основные первичные источники: K01 — буксировочный кайт *(отдельный исходник не входит в этот комплект / external source not included)*,
K02 — датчики и навигация крыла *(отдельный исходник не входит в этот комплект / external source not included)*,
K03 — автономные циклы *(отдельный исходник не входит в этот комплект / external source not included)*. Прямые судовые аналоги:
SkySails *(отдельный исходник не входит в этот комплект / external source not included)*, Beyond the Sea *(отдельный исходник не входит в этот комплект / external source not included)*, Race for Water *(отдельный исходник не входит в этот комплект / external source not included)*.

## Что именно оптимизировать

Требование максимальной тяги переводим в максимум средней полезной компоненты силы
по желаемому направлению движения при допустимых крене, рыскании, нагрузке строп,
усилиях приводов, запасе высоты и доступной зоне полёта.
Иллюстрация проекции: `Fx = T cos(elevation) cos(azimuth)` — только при определённых
осях и азимуте относительно выбранного направления. В модели нужен полный вектор.

Большая сила может давать мало продвижения при сильной боковой составляющей.
Курс, снос, течение и сопротивление боковых поверхностей входят в целевую функцию.
При поперечном полёте следует учитывать пульсации тяги и усталость конструкции.

## Сравниваемые механические схемы

| Решение | Что даёт | Основная неопределённость |
|---|---|---|
| LEI, надувная передняя кромка | Возможность водного перезапуска как кандидат | Насос, утечки, ресурс ткани, запуск с ограниченной палубы |
| Закрытый ram-air foil | Аэродинамическая эффективность как кандидат | Вода внутри, удержание формы, возврат и запутывание |
| Управляющие линии с палубы | Меньше аппаратуры на крыле | Длинные линии, сопротивление, трение, захлёсты |
| Гондола под крылом + буксирный канат | Короткие управляющие линии | Масса гондолы, энергия, связь, герметизация и обслуживание |
| Мачта/стрела с захватом/рифлением | Повторяемый запуск и возврат | Масса, волна, зона захвата и аварийная посадка |

Это гипотезы сравнения, а не выбранная конструкция. Профиль, площадь и длина строп
определяются после расчёта сопротивления судна и требуемого сектора курсов.

## Контуры и измерения

Состояние крыла: ориентация, угловая скорость, направление/скорость движения,
натяжение, длина и скорость выдачи каната. Состояние судна: курс, качка,
скорость относительно воды/грунта, ветер, положение буксирного узла.
Для стенда сравнить энкодеры лебёдок, тензодатчики, IMU крыла и судна,
GNSS и направление каната. Выбор датчиков должен учитывать наблюдаемость состояния.

Первый алгоритм: оценка состояния → стабилизация → ограниченная траектория
восьмёрки → регулирование депауэра/натяжения → координация с курсом.
MPC/CasADi и оптимизация рассматриваются после работоспособного базового контура.
Частоты циклов назначаем по идентифицированной динамике и задержкам, а не из общей рекомендации.

## Автомат состояний

`STOWED → PRECHECK → DEPLOY → LAUNCH → PARK → TRACTION → DEPOWER → RECOVER → STOWED`.
Из рабочих состояний предусмотрены переходы в `FAULT`, безопасное парковочное положение,
депауэр или аварийное отсоединение — конкретный исход зависит от механики и обстановки.
У каждого перехода: входные условия, тайм-аут, подтверждение датчиками и действие при отказе.
Перезапуск после попадания в воду должен быть отдельным режимом.

Опасные тестовые сценарии являются частью технической разработки:
порыв, спад ветра, закрутка строп, потеря связи/датчика, заклинивание привода,
сбой питания, резкий манёвр, качка в момент захвата, нахождение людей возле линий.
Механизм разгрузки должен работать при отказе основного компьютера.

## Модели и проверка

Начать с точечной модели крыла и упругой стропы, затем добавить сегментированный канат,
реальные полярные характеристики, управление и движущееся основание.
KiteModels.jl *(отдельный исходник не входит в этот комплект / external source not included)* — сильный кандидат, однако AWE-сценарий с наземной
лебёдкой нельзя напрямую выдавать за модель катамарана.
K12 *(отдельный исходник не входит в этот комплект / external source not included)* мотивирует исследование спектра тяги вместе с резонансами основания.

Последовательность: программная модель → приводы и датчики на столе → наземный
малый кайт → малое судно с ручным резервом → прототип запуска → полный масштаб.
На каждом шаге сохранять конфигурацию, погодные измерения, сырые логи и видео.
