# Дополнения FreeCAD для ECONA

Интернет-анализ официальной документации и исходного кода выполнен
**10 октября 2026**. Выбор привязан к корпусу 13,6 м, тяге кайта,
BLDC, LiFePO4 и солнечной крыше; установка разрешена пользователем.

## Связка CFD

Исходный код CfdOF 1.37.3 задаёт диапазон OpenCFD **2206–2512** и Gmsh ≥4.15.
Он строже вводного README по нижней версии OpenFOAM. Ubuntu OpenFOAM 1912
этому не соответствует, поэтому установлен официальный **OpenCFD v2512**:
`/usr/lib/openfoam/openfoam2512`, с инструментами разработки и примерами.
CfdOF явно настроен на этот путь, ParaView `/usr/bin/paraview` и wrapper Gmsh 4.15.0
`environment/.local/bin/econa-cfd-gmsh`.

Gmsh и snappyHexMesh дают основные способы построения сетки.
Дополнительно собран cfMesh версии CfdOF; его установленная версия и результат
проверки записаны в `software/cfdof-dependency-check.txt`.
HiSA предназначен для высокоскоростной сжимаемой аэродинамики и в текущую
несжимаемую постановку катамарана/кайта не включён.

Для гидродинамики понадобятся домен двух поплавков, корректная ватерлиния,
плотность и вязкость, скорость 7–10 узлов, подходящая модель турбулентности,
VOF и граничные условия. Проверять временной шаг, сеточную сходимость,
силы и влияние границ домена. Для винтов различать MRF и вращающуюся сетку;
кавитация требует отдельной постановки, давления и проверки solver.
Для кайта CFD даёт аэродинамические характеристики заданной формы, а не
автоматическую систему полёта или безопасного запуска.

## Электричество и управление

FreeCAD моделирует корпус BLDC, ротор, крепления, охлаждение, места АКБ,
PV и электроники. Магнитный расчёт выполняется **PYLEECAN/FEMM или GetDP**,
схемы — KiCad, солнечная выработка — pvlib, динамика кайта — KiteModels,
управление/оптимизация — Python Control/CasADi, навигационный обмен — Signal K.
Это отдельные расчётные инструменты, не дополнения, заменяющие друг друга.

SheetMetal пока не требуется для основного композитного корпуса; вернуться
к нему при выборе гнутых металлических деталей. Lattice2, сторонние сборочные
верстаки и DynamicData дублируют доступные для текущей стадии встроенные инструменты.
EM Workbench с FastHenry/FasterCap не заменяет магнитный расчёт BLDC.
Полного специализированного верстака «катамаран + кайт + PV + АКБ» в изученных
официальных проектах не найдено: системы увязываются через общие параметры и обмен данными.

## Проверки и повторный запуск

Список загрузившихся верстаков: `software/freecad-addon-startup.json`.
Обычное обнаружение и активация всех четырёх дополнений при новом запуске
FreeCAD также проверены в отдельном GUI с тестовым профилем:
`software/freecad-addon-fresh-start.json`, повторение —
`python3 tools/ship/verify_addon_fresh_start.py`.
Геометрические эталоны и запись CFD-входных файлов:
`software/freecad-addon-verification.json` и
`calculations/verification/freecad-addons/addon-benchmarks.FCStd`.
Скрипт повторения в GUI: `tools/ship/verify_extra_addons_gui.py`.
Выполнение созданной CFD-задачи и проверка сетки записаны отдельно в отчёте установки.
Основную модель открывать отдельно от эталонов; после обновления дополнений
повторить эти проверки. Commit каждого репозитория и SHA архивов зафиксированы.
