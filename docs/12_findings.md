# Выводы первой итерации

Количественное развитие на 10 октября 2026: [обзор концепта и PDF](23_concept_analysis.md).
Числа сценариев не назначают фактические массы, материалы или расчётную ватерлинию.

**Подтверждено открытыми первичными источниками:**

- Судовая кайт-тяга уже реализована; доступны прямые исследования управления буксировочными кайтами K01 *(отдельный исходник не входит в этот комплект / external source not included)* и датчиков K02 *(отдельный исходник не входит в этот комплект / external source not included)*.
- Механика запуска/возврата — отдельная подсистема: есть опубликованные патентные варианты [P01–P03](08_patents.md).
- Signal K — шина данных, OpenCPN — картплоттер, pypilot — судовой автопилот; их роли взаимодополняются [сравнение](07_navigation.md).
- OpenPlotter применим и на desktop Linux с ограничениями части аппаратных функций N04 *(отдельный исходник не входит в этот комплект / external source not included)*.
- ISO 12215-7 адресует многокорпусники; ISO 12217-2 требует отдельного рассмотрения эффектов буксировки [корпус](03_hull.md).
- PYLEECAN/FEMM проверены на Linux через отдельную среду и Wine на магнитном эталоне; расчёт нашего BLDC ещё не выполнен. Gmsh/GetDP остаются альтернативным ядром [стенд](20_software_completion.md).
- QBlade CE имеет non-commercial лицензионное ограничение; в свободное расчётное ядро пока не включён T02 *(отдельный исходник не входит в этот комплект / external source not included)*.

**Инженерные выводы проекта, которые ещё предстоит подтвердить расчётом:**

Максимизировать нужно полезное продвижение с ограничениями по нагрузкам,
а не абсолютное натяжение. Контроллер кайта и судовой автопилот координируются,
сохраняя собственные локальные контуры. Скорость 7–10 узлов рассматриваем как
целевую при подходящем ветре; возможность такой скорости в штиль пока не установлена.

**Ещё не определено:** водоизмещение, LWL, ширина и материал; площадь крыла и полярные
характеристики; схема запуска; мощность/топология мотора и винт;
площадь PV, ёмкость батарей, срок автономности и окончательная бортовая платформа.

Источники прошли первичный отбор. Подробное изучение всех полных документов,
исчерпывающий патентный поиск и экспериментальная проверка впереди.
