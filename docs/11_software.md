# Программы проекта

**Актуализация 10 октября 2026:** OpenCPN, ParaView, OpenFOAM, Octave,
KiCad и отложенные pypilot, OpenPlotter, Julia/KiteModels, PYLEECAN установлены.
Добавлены CfdOF, Curves, Fasteners и KiCad StepUp; для CfdOF установлен
поддерживаемый OpenCFD v2512 и собран cfMesh-CfdOF 1.32.
[Полный список, проверки и команды запуска](20_software_completion.md),
[дополнения FreeCAD и их применение](21_freecad_addons.md).

Дополнение от **10 октября 2026**: установлен и загружен FreeCAD Ship с 16
командами, Plot и Capytaine 3.0.0 в собственном Python 3.11 FreeCAD.
FEM настроен на комплектные CalculiX 2.23 и Gmsh 4.15.0; последний отличается
от проектного Gmsh Python 4.15.2. Проверены гидростатика раздельных поплавков,
веса/танк, посадка, GZ, выполнение RAO, график и объёмная сетка FEM.
Два локальных файла Ship исправлены для раздельных сечений и Capytaine 3.
Подробности, версии, ограничения и повторяемые проверки —
[в справочнике Ship](19_ship_workbench.md). GUI и MCP сейчас проверены;
пометка об их непроверенности ниже относится к первой итерации 9 октября.

Проверено 9 октября 2026 на Ubuntu 24.04.5, x86_64, 32 ГБ RAM.
Рабочее окружение Python — `.venv` в каталоге проекта. Глобальный Python не изменён.
Пакеты зафиксированы в `requirements.lock.txt`; результаты проверок —
`software/verification.json` и `software/logs/`.

## Запуск

```bash
tools/start-library
tools/start-jupyter
tools/gmsh
tools/start-signalk-demo
.venv/bin/python calculations/energy_budget.py
.venv/bin/python tools/verify_environment.py
.venv/bin/python -m pytest -q calculations
python3 tools/search.py "tether force"
```

В меню приложений добавлены отдельные ярлыки библиотеки катамарана, JupyterLab,
Gmsh и Zotero. Веб-сервисы исследовательские, без автозапуска при загрузке.
Демонстрация Signal K содержит **синтетические/примерные судовые данные**,
она не подключена к датчикам, рулям, моторам или кайту. Остановить: `tools/start-signalk-demo --stop`.
Библиография `research/library.ris` подготовлена для импорта в Zotero;
импорт в пользовательскую библиотеку не выполнялся.

## Дополнительный установленный стенд

Основные приложения установлены из репозиториев Ubuntu; для OpenCPN
сторонний PPA не потребовался. CfdOF настроен на официальный OpenCFD v2512.
Проверены окна OpenCPN/ParaView/KiCad, расчёт cavity и выполнение собственной
задачи, записанной CfdOF. Отложенные четыре инструмента установлены в отдельные
совместимые среды. PYLEECAN связывается с FEMM через Wine; выполнен магнитный эталон.

Путь запуска, версии, происхождение, численные проверки и границы готовности
приведены в [сводной инструкции](20_software_completion.md).
QBlade CE не входит в основное ядро из-за лицензии и специализации.
Платные комплексы и подписки не оформлялись.
